Google 연결

최초 1회 설정

  1. 1

    Google Cloud Console에서 새 프로젝트를 만들고 Google Drive API를 사용 설정합니다.

  2. 2

    OAuth 동의 화면을 만들고 테스트 사용자에 본인 Google 계정을 추가합니다.

  3. 3

    웹 애플리케이션 유형의 OAuth 클라이언트를 만들고 현재 사이트 주소의 원본을 승인된 JavaScript 원본에 추가합니다.

  4. 4

    발급된 클라이언트 ID를 위 입력란에 저장한 뒤 연결합니다.
