  visibility event made zero credential calls. One foreground function now
  rechecks wall-clock expiry on online/pageshow/focus/visible; hidden/offline
  do not fetch. Credential renewal never reopens or unpauses the player.
- Holding a metadata credential response and closing the player left a callback
  alive beyond the source's two-second cleanup wall; retirement settled false.
  Drive consumers now cancel their wait promptly while the shared auth request
  stays available to other consumers. Existing account/request checks still run
  before a retry. Expired-before-fetch and rejected401 are both covered.
- Expanded actual-app audit found that a page fetch abort alone did not prevent
  the SW replaying a401 Range after close. The preserved failed report shows
  settled page cleanup plus one unwanted fresh-credential Range. Q1 reads now
  request an affirmative page lease for exact file/session/source/account before
  using a credential. Both pre/post-refresh page checks apply; the cached-newer
  revision branch also requires the lease. Missing/false/timed-out replies cannot
  fall back to SET_TOKEN cache. Rejected401 body cleanup precedes final handshake.
  Generic/thumbnail credential behavior is retained.
