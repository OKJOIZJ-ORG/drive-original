# Drive Original v1.20.0 — comprehensive audit

Date: 2026-09-17. Baseline: `645914986daf09b335cdc106aec6b87e1f7c3fb9` / v1.19.1.

## Scope and preserved contracts

The existing repository instructions, decision ledger, source, tests, deployment workflow and canonical maintenance page were read before implementation. The review covered `app.js`, `sw.js`, `index.html`, `styles.css`, manifest/icon references, all existing tests and release documentation. This is a personal static PWA: no application server, analytics, account database or runtime framework was introduced. Original-byte-first playback, one video decoder, full-population navigation, Korean UI and the historical blue-dot icon remain intact.

No real Drive file was moved or deleted during verification. Faults and mutations used intercepted synthetic fixtures. The canonical Notion page is accessed only through local `ntn`, never a Notion plugin.

## Reproduced defects and repairs

| Area | Reproduced failure | Implemented repair |
|---|---|---|
| Bulk selection | Favorites resolved selected IDs against the underlying folder; empty selection fell through to the last player item | Current-population selection, empty-selection fail closed, cancelled select-all ownership |
| Account state | Two devices read the same JSON and overwrite one another's unrelated edits | Per-writer private appDataFolder documents, legacy read-only merge, same-writer Web Locks, deterministic equal-time unlike tie |
| Account identity | Late HTTP headers/JSON or initialization could commit after account invalidation | Auth and data generations, abort controllers, candidate-token identity verification before publishing a background refresh |
| Cleanup | An old media job could delete the next job's OPFS file; a new tab swept another tab's active file | Session-scoped cleanup and per-file lifetime leases; only unleased protocol-v2 files are swept |
| Rate limits | App-side Retry-After was shortened to ten seconds | Preserve the server delay and release retry abort listeners after completion |
| Failure routing | `rangeSatisfied=false` on ordinary 403/503 errors masked their actual causes | Invalid-range classification restricted to range failures, leaving auth/permission/server/network recovery distinct |
| Shorts | Backward slots consumed unseen candidates before the next forward item | Near-forward initial assignment and unseen-first continuation without altering reverse history |
| Keyboard | Focused seek keys also triggered global seek/volume shortcuts; Space on a button and browser modifier shortcuts were hijacked | Consumed local handlers, native activation and modifier preservation, focus-visible chrome stays available |
| Touch | A single-tap timer fired inside the double-tap window; delayed taps/scrubs affected later media | One 320ms recognition window, media ownership and shared cancellable pointer seeking |
| Large libraries | JS inferred a different column count/gap than mobile CSS; unchanged lists sorted on each scroll | Computed CSS grid geometry and cached sorted/filtered projections with invalidation |
| Offline shell | Version query cache misses; cache quota broke good responses; reset affected sibling applications | Canonical public-shell keys, cache-write isolation, exact app worker scope and owned cache prefix |
| Release | The entire repository was a Pages artifact with no test gate | Release-command syntax and regression gate, explicit twelve-file public branch (including `.nojekyll`), internal files excluded |
| Responsive UI | 320px header/control labels wrapped; primary/secondary/destructive text contrast failures | Compact three-row mobile toolbar, stable text and sizes, separate accessible action colors, 44px touch controls |

The initial fifteen new deterministic regression tests all failed against the starting implementation; after repairs they passed. A separate synchronized two-device write reproduction failed before the per-writer protocol and passed afterward. The current Node suite contains 120 tests and passed three consecutive full runs before release verification.

## Mobile left-edge back

The user specifically requested a higher-quality Apple-like left-to-right edge gesture. The former 0.34-distance/72px capped nudge and short fade were replaced by direct foreground tracking and an inert, bounded preview of the actual previous visible view. The underlying page shifts by 25% of the remaining width and a dimming layer clears as the gesture completes. A short drag returns smoothly; release uses recent 100ms movement rather than whole-gesture average speed, and a deliberate reverse flick cancels.

One owned History API entry is added synchronously with each folder/filter navigation. Back restores the previous folder, actual filter, search, sort, visible-window data and scroll position, rather than always returning favorites to `all`. Six recent pages retain heavy data/visual snapshots; older entries reload their lightweight route. File mutations invalidate retained data. A gesture never commits after interruption, account/view replacement, multiple touches, an open dialog, a player transition, or a browser-owned noncancelable event. New intentional clicks are not swallowed as ghost clicks.

iOS Safari browser physical-edge input is reserved for the native history gesture; its `popstate` uses the same restoration path. The inset edge and other custom-gesture environments use the app animation. WebKit's native-policy test is not proof of a physical iPhone system gesture.

Observed browser checks include 176px finger displacement producing exactly 176px foreground displacement; restored parent scroll=120px and all 60 fixture records; short-drag and reverse-flick cancellation; vertical-scroll handoff; second-finger cancellation; interruption during completion; reduced motion; previous-filter restoration; and the iOS/WebKit native-history policy.

Production OAuth with the user's account, actual two-device Google propagation, real cross-drive moves and physical iPhone OS gestures remain live-device evidence, distinct from the successful deterministic and browser fixtures. The Desktop connector returned `Tool observe not found`; installed browsers and Core image readback supplied visual inspection instead.
