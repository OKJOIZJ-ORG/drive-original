# D083 기능·UI/UX 개선 — 2026-10-04

1.23.0에서 확인한 결함과 사용성 요청, Desktop/drive original의 다섯 이미지 파일명 지시를 대상으로 한다. iOS는 사용자 검증이며 이번 실행 대상에서 제외한다. Emil은 참고 자료로만 사용하고 화면을 직접 확인했다.

## 구현과 원인

- 배속 버튼과 메뉴를 실제 playbackRate에서 함께 갱신한다. 영상 전환 시 1배 초기화 정책을 유지한다.
- 설정 일반 진입은 최상단으로 초기화한다. 도움말은 접힌 고급 안내를 펼치고 기존 항목으로 이동한다.
- 이미지/영상 탐색 이름을 갱신한다. 숨김/비활성/닫힌 details 내부를 제외한 플레이어 제어에서 Tab과 Shift+Tab을 순환하고 원래 카드로 돌아온다.
- MP4 트랙 확인의 반복 moov 읽기와 작은 Range마다 발생하던 버전 확인을 줄였다. 한 번 읽은 제한된 메타데이터를 정확한 원본 버전에서만 재사용한다. 샘플 인덱스 한도는 재생에 그대로 유지하고, 메타데이터로 확인한 긴 영상의 목록과 전환 제한을 구분한다. 전체 확인은 30초 한도이며 실패 후 다시 확인/재개방 안내를 제공한다. 메뉴 닫기와 영상 전환은 이전 요청을 종료하고 화면 갱신을 차단한다.
- 카드 제목은 두 줄, 명시된 EP/PART만 기존 보조 정보에 표시한다. 제목 버튼의 전체 파일명 창은 키보드와 터치로 열린다. 다운로드 제한 표시는 보존한다.
- 하위 폴더 포함은 현재 폴더에서 시작해 각 하위 폴더의 모든 페이지를 읽는다. 완전한 결과만 캐시에 반영하고 취소·계정·화면 변경을 구분한다. 폴더 밖 좋아요 조회는 유지한다.
- 짧은 탐색은 작은 단일 피드백을 제공한다. 지속되는 버퍼링은 작은 대기 표시, 오류는 기존 복구 UI로 남긴다.
- 제목 옆에 검증된 원본 전송 여부와 실제 해상도를 작게 표시한다. 외곽·조작 여백은 오버레이를 즉시 숨길 수 있고 중앙 재생/정지 및 버튼 동작을 유지한다.
- 보기 버튼의 네이티브 탭 강조와 터치 hover 잔류를 제거하고 경로/필터 정렬, 모바일 제목·닫기·진행 막대 간격과 더보기 메뉴를 정돈했다. 메뉴는 라이선스를 포함한 Lucide SVG를 사용한다.

## 한계

트랙 확인은 제한된 MP4 메타데이터와 지원 형식 안에서 수행한다. 목록 존재와 실제 전환 가능성은 별개다. 대체 트랙의 존재를 파일명이나 관찰된 대기로 추측하지 않는다. 장시간 재생, 전체 코퍼스 및 iOS 통과는 이 기록에서 주장하지 않는다.

초기 기기 도구 실패(controller없음/비슷한 길이 표본 중복)는 통과가 아니다. 첫 운영 실행은 짧은 영상 이후 긴 영상 시작45초 시간 초과로 실패했다. 당시 세부 전송/미디어 trace가 없어 원인은 미확정이며, 이를 SW 교체 문제로 단정하지 않는다. 실제 활성SW 판별과 실패 상태 저장을 보강한 다음 정상 운영 재실행은 전체 통과했다. 제품 소스 재변경이나 재배포로 통과시킨 것은 아니다. 모든 prior 실패 JSON을 유지한다.

직접 시각 검토에서 추가 발견한 메뉴 SVG 크기 누락과 긴 영상의 기본 음성 빈칸은 수정했다. 트랙 deadline 중 cleanup/import 경쟁도 핵심 테스트로 보완했다.
