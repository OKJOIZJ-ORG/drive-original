## Earliest bounded candidate, not yet authorized implementation

Avoid a bare retained suffix pushed directly to the worker: it skips the fresh metadata barriers that presently occur after probe/MSE startup. Same reader/generation checks alone do not observe a revision/permission/checksum change in that interval.

A conservative candidate is a **source-owned, single-use admission lease** for copied bytes of the selected window's suffix only, on the same unchanged reader/generation. For a subsequent logical read fully covered by that lease, the reader still runs its existing current/account/source checks, fresh preflight metadata and fresh postflight metadata, withholding bytes until both pass; only the duplicate body GET is omitted. Every new noncovered read keeps exact206/Content-Range/length, strong checksum upgrade, shared cancellation/deadline/concurrency and original metadata fences. No async callback/cache handoff, cross-seek/reader reuse or retry-budget replenishment is allowed. Release the owned suffix on consumption, cancellation, failure, reader replacement or retirement; add its≤1MiB lifetime bound to the existing probe retention accounting. Existing262144B logical read /65536B bootstrap push and worker credits/ACK/offset sequence stay unchanged. A partially covered logical read should initially use the old fresh read rather than combine old/new segments: the5s synthetic counterexample shows why partial overlap alone need not eliminate a request.

This conservative complete-read candidate saves response-body requests only where the selected suffix covers a full logical chunk. It preserves the metadata barriers rather than promise reducing the currently measured metadata waits. A later shared fenced read/coalescing design can be evaluated only with exact interval evidence, canonical source ownership and byte-equality/permission/drift/checksum/503/retirement counterexamples. Existing188 alignment and original audio/video PES/GOP preroll selection stay owned by `prepareTsSeekInput`; no RAP-only shortcut or dropped audio is proposed.
