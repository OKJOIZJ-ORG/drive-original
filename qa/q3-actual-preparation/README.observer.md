explicitly with `node qa/q3-actual-preparation/bind-observer.cjs --bind

runtime assets; the root alias makes47 cached entries. Public61 also includes

source hash fallback. The LGPL source archive is unchanged by these helpers.

Prepare all stages before timed work, using root-owned actual controls:

1. Upload the exact disposable fixture with the separately owned disposable
   controller. Capture fresh metadata and call its `installTarget()`. It places
   `{metadata,account}` privately in `__q3ActualTarget33`; then release the
   uploader. Never print that holder, file names/IDs, account IDs or credentials.
2. With the actual app closed/retired and visible, evaluate the bound
   `source-proof.expression.js`. It checks five network blobs, all46 cached
   blobs, root alias and the active registration, then privately installs
   `__resumeSwProof`. Its existing `executingWorkerScriptHashKnown:false` limit
   remains; server/cache hashes do not identify already executing script bytes.
3. Evaluate `observer.expression.js`, then call
   `__q3ActualReplay33.metadata('before')`. Exact generated SHA256 plus server
   version, stable metadata and every known strong field are mandatory. The
   observer's metadata-before gate rejects arming without that receipt.
4. Call `arm('native')` before the real UI file selection. Observe Q0 error4 and
   offered choice. Call `arm('startup')` before physically/native clicking the
   lossy choice. Startup records the actual source frame without requiring a
   zero-time reset or overriding app resume behavior. Call `arm('seek50')`
   before UI seek90s and `arm('seek90')` before UI seek162s; those percentages
   are bound to180s. Arm `cancel` before UI close
   while the Q3 stream remains active. The observer records `diagnosticAt15`
   and actual first-target-frame latency, including slower/failing work.15s is
   a diagnostic, not a functional completion threshold. Save completion requires
   current target frames/fences and an active stream at cancellation arm within
   the prepared finite observer bound. Performance acceptance stays separate.
   No helper invokes input/play/choice/seek.
5. After close/retirement, call `metadata('after')`, then `save()`. This captures
   current and retained retired-generation metrics, writes only the sanitized
   `__q3ActualReceipt33`, and stops timers/listeners/RVFC. Export that sanitized
   receipt to a root-owned safe JSON file. Android's prepared `save` command takes
   a new `actual-android-q3-observer-receipt-<label>-safe.json` name, validates the
   bound sanitized/stopped receipt, writes it locally (≤2MiB), and prints only
   saved/complete booleans. A `complete:true` value covers this
   bounded route/geometry/seek/close unit only, not whole Q3 acceptance.
6. In every failure path, export `read()` if available, call `stop()`, close the
   app through actual UI, wait for retired ownership, and call the disposable
   controller's `clearTarget()`. Clear private proof/holder/helper references
   after saving and release only the root-owned CDP/MCP/ADB transport. Never
   fabricate input/events or overwrite a retained failed receipt.
