# Source-built audio codec: notices and corresponding source

The distributed `media/audio-codec.wasm` is a static source-built AC3/EAC3 decoder using FFmpeg n8.0 libraries, a modified MPL-2.0 bridge derived from @mediabunny/ac3 1.60.0, and Emscripten 4.0.15. FFmpeg is licensed under LGPL 2.1 or later; the supplied configuration disables GPL and nonfree features. FFmpeg copyright and authorship are retained in the complete source archive. The bridge and adapted JavaScript source retain Vanilagy and contributors' copyright and MPL notices. Full LGPL, MPL, Emscripten, musl and compiler-rt notices are supplied in the package and `media/audio-codec.LICENSE.txt`.

Corresponding source is available beside this notice: `audio-source-manifest.json`, `audio-source-reconstruct.cjs`, and every numbered `audio-source-v1.tar.gz.partNNN` named by that manifest. These are complete byte-preserving parts of one source package, not source fragments. Download them together, run `node audio-source-reconstruct.cjs`, then `tar -xzf audio-source-v1.tar.gz`. Read `audio-source/README.md`. The manifest provides archive, part and individual material hashes. No external source CDN is required for the supplied source material.

The package includes complete pinned official FFmpeg, Emscripten and emsdk source archives, original and portable build recipes, generated configuration, modified bridge/wrapper source, bridge object, static FFmpeg libraries, post-JS and license texts. These materials permit modification and relinking with a compatible Emscripten compiler; the included object/static libraries provide a path that does not require recompiling FFmpeg. The compiler executables/cache are separate build prerequisites. A compiler installation is not silently performed by these instructions.

The archive preserves its preparation-time JavaScript wrapper snapshot. The current readable adaptation source is also distributed directly with the current runtime: [audio-runtime.mjs](../media/audio-runtime.mjs), [audio-adapter.mjs](../media/audio-adapter.mjs), [audio-worker.mjs](../media/audio-worker.mjs), [audio-worker-client.mjs](../media/audio-worker-client.mjs), [audio-general-pipeline.mjs](../media/audio-general-pipeline.mjs), and [audio-general-worker.mjs](../media/audio-general-worker.mjs). These unminified files are the preferred source for modifying the currently delivered JavaScript adaptations; retain their copyright and license notices. In particular, current native-file capability selection is in the readable source rather than the older archive snapshot. The decoder bridge, generated glue and WASM remain the exact archived build/relink target below.
