License files
  heif-decoder.LICENSE.txt contains the libheif LGPL-3.0 and MIT notices.
  heif-decoder-package.LICENSE.txt contains the libheif-js LGPL-3.0 text.
  The complete source tarballs also retain upstream COPYING/LICENSE files,
  including libde265's LGPL-3.0 notice.

Documented rebuild route (not executed here)
  1. Extract the libheif-emscripten v1.23.5 and libheif source archives, and
     restore the submodule at the recorded libheif commit.
  2. Use the included build-emscripten.sh with libde265 1.0.15; the included
     upstream CI workflow records Emscripten 3.1.61, Node 24, and TypeScript 5.
     Its build runs the libheif CI install/prepare/build scripts and dist-prep.sh.
  3. Use the included libheif-js v1.23.5 source and install/bundle scripts to
     produce the browser package, then compare its generated bytes and API with
     the pinned runtime asset before replacing anything.

This records an available source and build path. It is not a claim that this
archive has been rebuilt or that a byte-for-byte reproducible build was proven.
